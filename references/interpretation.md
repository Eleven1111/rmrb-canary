# 推论规则与弃权条件

## 一、已废弃的判断前提（不得再作为自动推理的依据）

下列表述在旧版 skill 中被当作规律使用。它们没有样本、没有定义、没有标定，
本轮全部撤下。若报告中出现同类表述，属违规。

| 旧表述 | 问题 | 替代 |
|---|---|---|
| 安全叙事使传导快 2–3 倍、协商余地接近零 | 无样本、无定义、无标定 | 安全议题可能影响政策工具选择；执行力度由文件、对象、动作证据判断 |
| 三部委以上发声即行动倒计时 | 把提及、表态、联合发文、执法混为一谈 | 分别记录：机构共现 / 同议题表态 / 联合文件 / 明确执行分工 |
| 国常会后 30–60 天必出细则 | 把可能的经验变成期限承诺 | 有明文截止日就引用；否则记为待观察事件，不承诺天数 |
| 集体学习领先政策 6–12 个月，未兑现可用节律解释 | 缺乏可证伪条件 | 单列为关注信号；预设观察窗口、失败标签与解释更新规则 |
| 政论文章意味着方向不可逆 | 把政治表达等同政策状态 | 记录权威表达及其对象范围；再检索正式文件与后续修订 |
| 沉默、关评、未跟进意味着刻意管控 | 可观测事实不足以证明动机 | 先说明覆盖、平台机制与采样缺口；动机最多作为竞争假设 |
| 中西政策传导各只有一种模式 | 过度概括 | 并存试点、立法、预算、常态监管、专项行动等路径 |
| 相对变化天然比绝对数可靠 | 趋势本身也会算错（F01–F03） | 只有同口径、同覆盖、同版本时才允许比较 |
| 跳级突变 = 中央已决策，窗口 30 天内 | 当期等级并存被当成时间跃迁 | `level_spread` 只描述当期措辞差异；跨期变化看 `trend` |

**"官方实际在想什么"已从报告目标中移除。** 报告回答的是：公开表述、正式措施与
可观察执行之间有哪些差异。可以推断，但必须说明证据不足之处。

## 二、优先回答"变化对比"，而不是更复杂的总分

1. **措辞变了吗？** 同一对象从"鼓励"到"要求"，是否有直接上下文支持？
2. **范围变了吗？** 试点扩围、对象新增、门槛变化、豁免取消？
3. **责任变了吗？** 是否首次出现牵头部门、配合单位、检查责任、问责条款？
4. **资源变了吗？** 是否出现预算、额度、采购、人员或具体项目安排？
5. **程序推进了吗？** 征求意见 → 正式文件 → 地方实施细则？
6. **执行兑现了吗？** 宣布的动作是否按预期落地，哪些地区滞后？
7. **方向分化了吗？** 是否支持行业总体发展、同时限制其中某种商业模式？

每项变化输出：旧证据 / 新证据 / 适用范围 / 判断影响 / **替代解释**。
没有对应旧版本时只能写"本系统首次观察到"，不能写"官方首次提出"。

## 三、语义陷阱（P1 已程序化，仍需人工复核 needs_review）

规则层已经实现下列区分，结果在 `events` 里逐条可查：

| 陷阱 | 程序如何处理 | 仍会出错的地方 |
|---|---|---|
| "不得随意查封企业" | 否定 + 执法工具 → 方向记为"约束执法行为" | 否定范围跨分句时会错 |
| "去年依法查处……" | `tense='historical'`，`is_new_action=false` | 无时间词的历史叙述判不出来 |
| "支持行业发展，同时整治违法收费" | 拆成两个分句事件，第二条 `applies_to_topic=false` | 代词回指的对象判不出来 |
| "拟/研究/征求意见" vs "决定/自某日起施行" | `procedural_status` 分类 | 一句含多个状态时只能全部列出 |
| 地方 / 中央 / 市场主体 / 被引述观点 | `subject_level` + `authority` | 主体省略的句子记为"未识别" |
| "有关部门" | 记为官方但 `subject_level='未指明机关'`，强制待核验 | —— |

### 模型抽取的契约

模型可以在规则候选之上做结构化抽取，但产出必须能过 `evidence_check`：

1. 每个字段的取值必须**逐字出现在它自己的引文里**；
2. 文号、日期、生效时间只能照抄原文，**不得补全**；
3. 引文必须在本期原文中逐字存在；
4. 关键实体不明确、多个解释无法消解 → 输出"待核验"，不要挑一个填上。

未通过核验的抽取会被程序强制降级为待核验，不会进入维度汇总 ——
这不是提醒，是门槛。

## 四、企业影响的推导链

```
可核验政策变化 → 企业暴露环节 → 可能影响 → 可逆行动 → 升级触发条件
```

例：新增技术标准 → 先确认产品范围、过渡期与企业产品映射 → 再建议评估改造成本。
**不能**从"国家安全"四个字直接推出退出行业。

议程重要性、企业相关性、新颖度分别展示，不合并成一个总分。

## 五、弃权条件（出现任一情况，该维度输出"不判断"）

- 对应分析块 `status='unknown'`；
- `signals.status != 'ok'`，却要写方向、工具、程序或执行结论；
- 结论所依赖的事件 `evidence_verified=false` 或 `needs_review=true`；
- 企业影响推导时 `exposure.relevance` 为 `unmapped` / `no_profile`；
- `fetch_quality.status != 'complete'` 且结论依赖"没出现"这一事实；
- 无历史基线，却要下"变化"结论；
- `comparable=false`，却要比较两期数值；
- 关键实体（谁对谁做什么）无法从原文确定；
- 唯一支持证据来自转载或同体系重复报道。

弃权是合格输出。**"本期没有足够证据形成新增判断"必须允许被写出来。**
