# 董事长简报模板

**触发：** 用户说"简报""日报""董事长版"。这是写作模式，**不是** CLI 参数
（旧文档里的 `--brief` 并不存在）。

**前置：** 企业画像来自 `config/enterprises/<key>.json`（当前已配置 `bgi` 华大基因）。

华大基因的 `chair_focus` 已确认为**双方向**：`监管合规` + `政策窗口与机会`。
简报必须**双镜头并列**，取 `signals.by_chair_lens` 的两组事件：

- 两段各自独立，各有自己的证据与建议动作。
- 某一方向本期没有可核验证据 → 写"本期该方向无新增证据"，
  **不得**用另一方向的内容填充。
- **不得**把两者揉成一段泛泛的"机遇与挑战"—— 那等于两个方向都没回答。

---

```
# [企业行业] 政策信号简报
**[日期]** ｜ 分析截止：[as_of] ｜ 采集质量：[status] ｜ 证据状态：[evidence_state]

## 今日变化

[一句话。格式："[谁]在[做什么]，这对你意味着[影响]。"
本期无新增变化时，直接写"本期没有足够证据形成新增判断"，并说明看了什么、为什么不足。]

**依据：** [来源 + 条款/原句 + 发布日期]

## 监管合规（0–2 条，允许零条）

**① [标题]** —— [两句：发生了什么、对本企业哪个环节意味着什么。附一处证据。]

（`by_chair_lens['监管合规'].count == 0` 时写"本期该方向无新增证据"。）

## 政策窗口与机会（0–2 条，允许零条）

**① [标题]** —— [同上。机会同样要有证据，不能靠语气渲染。]

（`by_chair_lens['政策窗口与机会'].count == 0` 时同样明说，不借另一方向的内容填。）

## 需要决策的事（如有）

因为[具体发现]，建议[具体的可逆行动]；[有明文期限则写日期，没有则写下一个观察节点]。
无需立即决策时明说。

## 仍待确认

[本判断中最不确定的部分，以及需要什么证据才能确认。这一节不许省略。
待核验事件数（signals.needs_review_count）不为零时，必须在这里说明它们是什么。]

## 一篇必读

| 标题 | 为什么读 |
|---|---|

选文两条并列，分别标注，不互相替代：
- **企业必读**：与经营决策直接相关的正式文件或报道，优先选它。
- **今日宏观议程**：版面权重最高的头版文章，单列。
  不把无关头条强行解释成企业信号。

纯数据发布类文章（展会数据、统计公报）不入选必读，除非数据本身异常。

## 背景数字（备查）

- 词语强度：[N级 或 未知]（较上期 [变化 或 无基线]）
- 机构信号：[等级 + 机构数]
- 报道量：[signal 或 门槛未通过]
- 时间：[原文明确日期，或"无明确日期，下一观察点：…"]

> 打分为未标定的词面特征；本框架不输出风险倒计时。
```

---

## 纪律

- 全文约 500 字，5 分钟读完。
- **500 字不是删掉证据范围的理由。** 必要的限定词与关键来源必须保留；
  真放不下就减少信号条数，不减证据。
- "今日变化"只允许写一件。
- 允许零条信号、允许写"本期无新增判断"。
- 按企业画像的暴露映射过滤信号；`chair_focus` 决定**分几组呈现**，不改变结论本身。
- 同一事件可能同时落进两个镜头（既给支持又提要求），此时两边都写，
  但要写清楚是同一件事的两面，不要伪装成两条独立信号。
- **间接暴露必须写成间接。** 例：疫苗议题对华大基因是 indirect ——
  经由疾控体系建设与病原监测波及检测服务；疫苗生产、批签发类政策通常不构成直接影响。
  把间接关系写成直接影响，是本模板明确禁止的错误。
- 暴露关系为 `unmapped` 时，本期不写企业影响，只写"需补登记暴露环节"。
- 不写"基本完成""综合来看""总体而言"。
