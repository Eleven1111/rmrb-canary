# 快照与信号定义

## AnalysisSnapshot

管道输出的唯一结果对象。报告、历史比较、存储三个出口共用它。

| 字段 | 含义 |
|---|---|
| `algo_version` | 算法版本。跨版本记录不参与比较 |
| `topic_id` | 主题身份。由 topic_key 固定；临时关键词口径取关键词哈希 |
| `topic_version` | 主题口径版本。口径变了就是另一条时间线，见 topics.md |
| `enterprise` / `exposure` | 企业画像与该主题的暴露映射（direct / indirect / unmapped / no_profile） |
| `events` / `extraction` | 事件层：候选事件与证据核验结果 |
| `signals` | 多维信号（七维），由通过核验的事件汇总 |
| `dedupe` | 来源归并：原发条数、转载条数、独立体系数 |
| `changes` | 事件级变化对比（七问） |
| `policy_documents` | 正式文件采集结果：命中文件、失败清单、不可用来源、覆盖警告 |
| `cache_report` | 共享文档缓存命中情况 |
| `alerts` | 本期告警：新建 / 更新 / 去重抑制 / 是否因回放而不投递 |
| `date` | 采集的报纸日期 |
| `as_of` | **分析截止时点**。所有历史查询只取严格早于它的记录 |
| `total_articles` / `total_scanned` / `topic_share` | 命中篇数 / 实际扫描篇数 / 主题占比 |
| `fetch_quality` | 采集健康度，见 source-policy.md |
| `scope` | 目标相关片段切分统计（片段数、涉及文章数、被排除句数） |
| `narrative` / `intensity` / `ministry` / `cooccurrence` | 四项判断，各自带 `status` |
| `clock` | 年度节律，**仅上下文**，无系数 |
| `timing` | 时间预期：明确日期 + 下一项可观察事件；`predicted_window` 恒为 null |
| `trend` / `coverage_change` / `rolling_trend` | 跨期变化 |
| `quality_gates` | 程序门槛，决定允许写出什么 |
| `known_limitations` | 本轮未修复项，必须随结论一起呈现 |

## 判断单位

**含目标关键词的句子**，不是整篇文章。标题单独成段。
片段带原文字符位置，每条判断都能指回原句。

已知召回损失：跨句指代（"该行业……"）会被漏掉；否定、历史回顾、引述观点
尚未识别（P1 事件抽取的职责）。

## 四项判断

### 叙事框架（narrative）
多标签，不互斥。给出各框架的加权得分与原文证据。
`multi_frame=true` 时不得宣称单一主框架。
**不输出**传导速度系数与协商余地 —— 那些没有标定依据，已删除。

### 词语强度（intensity）
七级词表，1 研究探索 → 7 专项打击。这是**词语强度这一项兼容特征**，
描述措辞，不导出政策阶段、不导出时间窗口。

- `phrase_share_pct`：短语命中的加权得分占比。**不是**段落占比、不是篇数占比。
- `level_spread`：当期不同等级并存，反映同一议题内部措辞差异。
  这**不是**"跳级"—— 跨期变化只能由 `trend` 给出。
- `status='unknown'` 时 `max_level` 为 null，不得用 1 级顶替。

### 机构信号（ministry）
只回答"哪些机构出现在目标语境里、以什么身份出现"，不回答"会不会执法"。

| 等级 | 判定 |
|---|---|
| `L5` | 目标语境中出现司法机关 |
| `L4` | 出现政治局层级**决策会议**表述 |
| `L3` | 出现国务院层级部署表述 |
| `L3-前瞻` | 只出现高层**学习活动**（集体学习/专题学习） |
| `L2` | 3 个及以上机构在目标语境中共现 |
| `L1+` | 2 个机构共现 |
| `L1` | 单一机构提及 |
| `L0` | 目标语境中无机构 |

- 会议事件类型**先于**机构层级判定：一句同时含"中央政治局"和"集体学习"的话是
  学习活动，记 `has_forward_signal`，不升级为 L4。
- 标签必须与实际机构数一致。
- `joint_document`：只有出现"联合印发/联合发布/共同印发"等措辞时才为 true。
  **机构共现 ≠ 联合行动 ≠ 执行分工**，三者分别记录。
- `signals_below_threshold`：加权得分不够升级门槛、但**已经观察到**的高层级信号。
  门槛只决定"要不要升级等级"，不决定"有没有看见" —— 降级不得抹掉事件类型。
  报告中这类信号写成"已观察到，权重不足以升级"，不能当作没发生。
- 不输出任何时间压缩系数。

### 语境（cooccurrence）
锚词是词面情感标记，未识别否定与历史回顾。
`signal_coexists` 只说明正负表述并存，**不等于**政策方向分化。

## 时间（timing）

- 有原文明确日期 → 呈现日期、类型（生效/截止期限/年度期限/意见反馈）与原句证据。
  每条日期带 `scope_level` 与 `applies_to_target`：
  `sentence` + `True` = 出现在目标句内，适用对象与目标一致；
  `article` + `unconfirmed` = 出现在同篇文章其他位置（如"本办法自X日起施行"），
  **适用对象需人工确认**，不得直接写成目标议题的期限。
- 无明确日期 → 输出"下一项可观察事件"，不给月份区间。
- `predicted_window` 恒为 `null`，`calibrated` 恒为 `false`。
- `evidence_state`：⚪ 证据不足 / 🟢 未出现高强度措辞 / 🟡 有原文明确期限或高强度措辞。
  这是**证据状态**，不是风险预测。

## 事件层（P1）

### 事件抽取
判断单位再降一级到**分句**。每个分句抽成一个候选事件：
主体 / 主体层级 / 动作 / 政策工具 / 方向 / 程序状态 / 约束强度 /
适用范围 / 地域 / 否定 / 时态 / 权威性 / 对象归属。

关键字段：

| 字段 | 含义 |
|---|---|
| `applies_to_topic` | 分句里有没有主题词。false = 对象可能不是本主题，**不进入方向汇总** |
| `authority` | official / quoted_opinion / non_official / unknown。被引述观点不是官方行动 |
| `subject_level` | 中央 / 地方 / 未指明机关 / 市场主体 / 非官方 |
| `tense` | historical / current / forward / ambiguous。历史回顾不计为本期新增 |
| `negated` | 是否含否定。否定 + 执法工具 → 方向为"约束执法行为"，不是整治升级 |
| `is_new_action` | 同时满足：官方主体、对象落在主题上、非历史、未被否定 |
| `needs_review` + `review_reasons` | 待核验及其原因。**不得直接进入已确认结论** |
| `confidence` | 规则抽取上限为 medium，永不为 high |

分工（§6.2）：规则召回与预结构化 → 模型结构化语义抽取 → 程序核验原文支持。

### 证据核验
`evidence_check` 对规则与模型的产出一视同仁，核验四件事：

1. 引文在原文中逐字存在；
2. 结构化字段里的每个词都出现在它自己的引文里；
3. 文号与日期不得补全 —— 写了就必须在引文中出现；
4. 字符位置若给出，必须有效。

未通过 → 强制 `needs_review`，`confidence` 降为 low，**排除出维度汇总**。
`evidence_completeness` 即方案 §9.2 的"证据完整率"。

### 来源归并
转载是**一个事件的多个来源**，不是多个独立证据。

- `original_count`（簇数）可作证据计数；`reprint_count` 只计传播强度。
- 同一体系（人民日报与人民网、新华社与新华网）不计为独立印证；
  跨体系印证数看 `cross_system_confirmed`。
- 归并按标题词面进行，改写标题的转载会漏掉。

## 多维信号（七维）

进入汇总的事件必须同时满足：对象落在主题上、官方主体、通过原文核验、非历史回顾。

| 维度 | 内容 |
|---|---|
| 政策方向 | 支持 / 限制 / 规范 / 混合 / 未明确 / 约束执法行为，各自计数并绑定对象。`coexists=true` 时必须分对象呈现，不得合成单一方向 |
| 政策工具 | 财政 / 税收 / 信贷 / 准入 / 标准 / 执法 / 采购 / 试点 / 规划 / 监测 |
| 程序状态 | 研究 / 征求意见 / 正式发布 / 实施 / 修订 / 废止。允许跳转与并行，不是线性阶段 |
| 约束与动作 | 倡议 / 具体任务 / 义务 / 责任 / 期限。看的是义务是否出现，不只看措辞强弱 |
| 适用范围 | 全国 / 地方 / 试点 / 例外 + 地域清单 |
| 执行证据 | 责任主体 / 细则或标准 / 资源安排 / 执行记录，四个构件分别判定。缺一即执行链不完整，**不得据此推断已落地** |
| 传播变化 | 版面位置、权威栏目、原发条数、转载条数、框架 |

此外 `signals.by_chair_lens` 按董事长关注方向分成两组（监管合规 / 政策窗口与机会），
各带证据。空的一侧显式为 0，不消失，也不许用另一侧填充。

七维并列，**不合成总分**。七级词语强度作为兼容特征另行呈现，不参与本汇总。
`needs_review_count` 本身就是信号：待核验越多，结论越不该说死。

## 告警（P2）

告警从"分数越线"转向"事件变化"。生成门槛：事件通过证据核验、对象落在主题上、
官方主体、非历史回顾。**待核验的东西不去打扰人。**

去重键 = `主题 + 事件指纹`。事件指纹只由语义构件（主体/方向/工具/对象/程序状态/范围）
决定，**不含**标题、URL、抓取时间 —— 否则转载就会变成重复告警。
`change_version` 由责任、范围、期限、文号、生效日期、文件状态决定，
它是判断"重复"还是"更新"的依据，**不进身份键**：进了键，每次变化都会变成
一条全新告警，状态机就跟不住同一个事件。

状态：`观察 → 待核验 → 已确认 → 待投递 → 已通知 → 跟踪 → 关闭/撤回`。
非法迁移会被直接拒绝。**投递尝试不等于送达**：发送失败留在"待投递"，
只有收到回执才推进到"已通知"并记 `notified_at`。

`as_of` 早于今天 = 历史补采/回放：告警只落库为观察态，`delivery_blocked=true`，
不触发实时通知。

延迟指标：发现延迟 = `first_seen_at − published_at`（发布时间只到日，按日计，
不冒充分钟精度）；通知延迟 = `notified_at − first_seen_at`。两者分开统计。

## 变化对比（七问）

`changes` 逐条回答 interpretation.md §2 的七个问题，每条给出
旧证据 / 新证据 / 适用范围 / **替代解释**。

状态：`ok` / `first_observation`（无基线，只能写"本系统首次观察"）/
`not_comparable`（口径不可比，不给结论）/ `baseline_unusable`。
